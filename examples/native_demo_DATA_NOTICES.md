# Native demo data notices

This three-case example contains original GLB images, aligned physical elevation and genuine source usability, and retained GlacioLens prediction masks. It contains no training labels or model weights. Its data terms are separate from the Apache-2.0 source and selected-weight license.

## Glacial-Lake-Bench imagery

Source: [Glacial-Lake-Bench, Zenodo record 17917359](https://zenodo.org/records/17917359), by Saurabh Kaushik, Beth Tellman, Ian Howat, Umesh Haritashya and Lalit Maurya, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The [dataset paper](https://doi.org/10.5194/essd-2026-474) credits the first four authors. Retain this attribution and applicable underlying-provider notices when sharing the samples. Original 11-band image values and TIFF bytes are unchanged; filenames are organized into portable per-case directories. Predictions are generated by GlacioLens and identified separately from reference labels. The example compilation retains the dataset attribution.

## Copernicus GLO-30 adapted elevation

The retained preparation records identify the public `copernicus-dem-30m` source bucket, the GLO-30 Public Cloud Optimized GeoTIFF variant described in the [AWS Open Data registry](https://registry.opendata.aws/copernicus-dem/). That provider describes the 2021 release and links the applicable free public product terms. The actual source tile IDs and preparation grid identities are in `dem_provenance.json` inside the example archive. They are historical source records, not a claim that source products were fetched again for this release.

Physical metres were bilinearly aligned to the native 10 m image grid, with EGM2008 vertical reference. The usability rasters are the genuine retained source-validity masks. These are adapted elevation products; neither elevation nor usability is relicensed as Apache-only. The exact prepared TIFF containers are preserved in this release.
