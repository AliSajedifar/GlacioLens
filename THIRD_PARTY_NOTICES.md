## Project adaptations and generated material

The scientific modules are project work projected from the accepted executed snapshot. `logical_loss.py` retains its acknowledgment of the user-supplied P02S project reference; `p22_spatial.py` retains its P22 reference description. These are project-reference provenance, not evidence of an external license grant or a named individual's authorship. The public repository is maintained by Ali Sajedifar (AliSajedifar); this maintainer credit does not invent a legal copyright history or additional authors. No external copied implementation requiring an additional MIT text was identified in the reviewed public members; this conclusion is based on source inspection and comparison, not just repository badges or a match score.

The configuration, aggregate metrics, synthetic example and aggregate score plot are project-generated material. The qualitative segmentation figure and the exact population/source/sampling metadata additionally contain explicitly attributed GLB/GLBC derivatives under CC BY 4.0; they do not include raw raster datasets or DEM samples. No upstream source notices were removed, no scientific bodies changed, and no new blanket `NOTICE` file is needed for these import-only dependencies. External asset terms are separately described in [licensing scope](docs/release_status.md#licensing-scope).


## GLB and GLBC data attribution

Glacial-Lake-Bench and Glacial-Lake-Bench-Challenge were introduced by Saurabh Kaushik, Beth Tellman, Ian Howat and Umesh Haritashya. The [dataset paper](https://doi.org/10.5194/essd-2026-474), Data Availability Statement, identifies [Zenodo record 17917359](https://zenodo.org/records/17917359) and explicitly states that GLB and GLBC are distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Dataset-derived images, labels and metadata retain these terms and any applicable source-specific attribution; they are not relicensed by this repository's Apache-2.0 code license. The [reproduction guide](docs/reproduction.md#dataset-version-and-split-sizes) identifies the pinned benchmark distribution used by the project.

The Zenodo record credits Saurabh Kaushik, Beth Tellman, Ian Howat, Umesh Haritashya and Lalit Maurya; the dataset paper credits the first four authors. The qualitative image `docs/figures/glaciolens_qualitative.png`, its provenance sidecar and dataset-derived `data/manifests/` records carry CC BY 4.0 attribution. Display adaptations are selected RGB bands, per-band percentile contrast stretching and a shared small-lake crop enlargement; predictions/error overlays are by GlacioLens. Metadata adaptations are exact population projections, portable source paths, retained alias annotations and lossless indexing of label-derived component/crop sampling records. No DEM imagery or sidecar array is redistributed.

## Saved-results reproduction data

The `results/reproduction/` bundle includes GLB TEST reference labels and original valid support, losslessly packed as binary arrays, plus generated predictions and derived per-tile/group statistics for the named systems. Preserve the GLB dataset's CC BY 4.0 attribution when redistributing this dataset-derived compilation. No reference-model weights are included. The new evaluation and rendering code uses the project code license, Apache-2.0; it does not relicense the dataset or upstream models. The full reference citation and distinctions between dataset-record and paper authors are recorded above.
